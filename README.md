# cpp-Library-Management-System

- 一个文字交互式单文件 C++ 图书管理系统，支持用户登录注册、图书管理、管理员对用户管理，并使用外部文件保存用户及图书数据。有分级菜单显示和跳转功能。

## 功能

### 1. 登录界面
- 用户登录
- 用户注册

### 2. 图书管理界面
登录成功后进入图书管理主页面，根据权限区分普通用户和管理员功能。

**普通用户功能：**
- 查找书籍
- 浏览书籍名单
- 借书 / 还书
- 查看排行榜（最多借阅榜、最新出版榜）

**管理员功能：**
- 拥有普通用户的所有功能
- 对图书的增删改查
- 对用户的增删改查

### 3. 分级菜单设计
- 采用两级菜单结构：先登录页面，登录成功后进入图书管理页面。
- 每个子页面均提供返回上一级页面的选项，操作流畅。

## 数据持久化

程序使用文件保存数据，实现记忆功能：
- 用户信息保存到：`userinfo.txt`
- 图书信息保存到：`bookinfo.txt`

**文件读写逻辑**：程序首次运行时，如果未找到对应的数据文件，会自动创建一个空文件；如果文件已存在，则直接读取文件内容并加载数据。

## 编译运行

如果使用 Dev-C++ 或 VS Code，直接下载并打开 main.cpp，编译运行即可。

Windows:
```bash
g++ main.cpp -o library.exe
library.exe
```
环境说明：本项目使用了 Windows 特有的控制台命令（如 system("cls")），建议在 Windows 环境下编译运行。如果需要在 Linux / macOS 下运行，请将代码中的 system("cls") 替换为 system("clear")，并移除或替换 system("pause")。

## 使用说明

- **初始状态**：本项目初始数据文件为空。首次运行时，需先注册账号。
- **权限说明**：本项目实现了简单的登录注册权限功能，但未对管理员权限的获取进行限制，即注册时可直接注册管理员账号获得管理员权限。
- **项目性质**：本项目为 C++ 学习项目，用于大学作业。
- **安全警告**：密码未加密存储；管理员权限获取无限制，请勿用于真实场景；文件写入需严格按照格式。
- **文件编码**：代码文件编码为 UTF-8。
